### 4.2 Hidden City Ticketing

```
What it is:
──────────
Book NYC → Tokyo, but get off in Honolulu (hidden stop)

Example:
├─ NYC → Tokyo (direct) = $1,200
├─ NYC → Tokyo via Honolulu = $650 (cheaper!)
├─ Book the 2-leg, get off in Honolulu
└─ Savings: $550!

Legal Status: Gray area
├─ Airlines say it violates terms
├─ But it's hard to enforce
├─ You might be flagged if you do it repeatedly
└─ Use at your own risk

When it works:
├─ Domestic USA flights
├─ International routes with connecting hubs
├─ Off-peak timing (less scrutinized)

When it doesn't work:
├─ If bags are checked through to final destination
├─ If you need checked bags
└─ If same airline (they track)

Risks:
├─ Account flagged
├─ Ticket cancelled
├─ Blacklisted
└─ But: Mostly theoretical, rarely enforced
```
