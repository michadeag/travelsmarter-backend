CRITICAL PATH (REQUIRED TO LAUNCH):
═══════════════════════════════════════════════════════════════════════════════

PRIORITY 1: BACKEND DEPLOYMENT (2-3 days) 🔴 CRITICAL
──────────────────────────────────────────────────────────────────────────────
Required before: Everything else

Steps:
  1. Create .env file with Stripe + SendGrid + Database credentials
  2. Create PostgreSQL database and seed data
  3. Implement Stripe webhook for payment processing
  4. Deploy backend to production (Heroku/AWS/DigitalOcean)

Verification:
  ✓ All 40+ API endpoints accessible
  ✓ Database working
  ✓ Stripe test payment works
  ✓ Webhook receives events

Why Critical: Without this, no users can sign up, pay, or save data.


PRIORITY 2: FRONTEND INTEGRATION (1-2 days) 🔴 CRITICAL
──────────────────────────────────────────────────────────────────────────────
Required before: Domain setup

Steps:
  1. Update index.html to load real data from API
  2. Update auth.html to use api.login/signup functions
  3. Update checkout.html to use Stripe payment flow
  4. Deploy frontend to production (Vercel/Netlify)

Verification:
  ✓ Can sign up → get email → log in
  ✓ Can view real hacks from database
  ✓ Can save hacks → persisted in database
  ✓ Can upgrade → payment works → tier changes

Why Critical: Without this, the app doesn't work.


PRIORITY 3: DOMAIN & SSL (1 day) 🟡 IMPORTANT
──────────────────────────────────────────────────────────────────────────────
Required before: Marketing launch

Steps:
  1. Register domain (travelsmarterapp.com)
  2. Configure DNS to point to frontend + backend
  3. Update API URL in frontend
  4. Enable HTTPS (automatic with Vercel/Netlify)

Verification:
  ✓ https://travelsmarterapp.com loads app
  ✓ https://api.travelsmarterapp.com accessible
  ✓ All requests use HTTPS

Why Important: Users won't trust unbranded IP addresses.
